Company Policy Assistant

Rules-based search vs. LLM without a vector index vs. LLM with a vector index (RAG), on a database of 98 company policies.

Comparison

We tested the three approaches on the same 21 questions: 16 that are covered by the 98 policies and 5 that are not. Rules-based search is by far the fastest (0.32 ms on average and 0 tokens), but it only found the right policy in 10 of 21 cases and gave an answer backed by the wrong policy in 10 cases. For example, it answered "Can I bring my dog to the office?" with the Office Access Policy, because it only matches words and does not understand that "trial period" means probation or that "hacked" is a security incident. The LLM without a vector index got 20 of 21 right and never gave an unsupported answer (its one miss was saying the database did not cover a hacked account, which is the Security Incident Policy). However, it has to send all 98 policies with every question, so it used 2,773.62 tokens per question on average. The LLM with a vector index got all 21 right with 0 unsupported answers and used 208.95 tokens per question, which is 92.47% fewer than without the index. It was 432.97 ms slower on average (2,724.95 ms vs. 2,291.98 ms), because it makes an extra embedding call before generating the answer.

We prefer the LLM with a vector index. It was the only approach that got every test question right, it said "not covered" to all five questions outside the database instead of making something up, and because it only sends the three most relevant policies, the token use and cost per question stay roughly the same even if the policy database grows. The LLM without an index would have to send the whole database every time, which gets more expensive and eventually hits the context limit. The extra 432.97 ms is not noticeable in a Slack conversation, so this is the approach our Slack bot uses. Rules-based search could work as a cheap fallback if the API is down, but on its own it is too unreliable, since a wrong answer that names a real policy looks convincing to an employee.
